# Data Availability

This repository contains everything required to replicate the findings of
*"Outlier Detection Methods Are Not Equally Resilient to Sampling"*.

There are two kinds of data:

1. **Derived data generated by this study** — the resilience result of every replicate
   (one CSV per dataset × method, per experiment) that directly underlies every table and
   figure of the paper. These are in `revision/experiments/*/raw/`, with the derived tables
   in `revision/experiments/*/tables/` and the Supporting Information tables in `revision/SI/`.
2. **Existing third-party benchmark data** — 29 public outlier-detection datasets (16 core
   datasets from ADBench, and 13 further ODDS/ADBench datasets used in experiments E2 and E2b).
   They are not redistributed here (they are git-ignored) but are downloaded on demand from
   their public sources by `download_datasets.py` and `revision/code/download_extra_datasets.py`.

The folder `archive/submitted_version/` holds the results and scripts of an earlier version of
the analysis. They are superseded and do not underlie the tables or figures of the paper.

---

> The minimal data set underlying the findings — the per-replicate resilience results
> (CSV) and the complete analysis code — is available in the OD_resilience_analysis repository
> (https://github.com/LaureBerti/OD_resilience_analysis), archived on Zenodo
> (all versions: https://doi.org/10.5281/zenodo.20829792). The benchmark datasets analysed are
> existing, publicly available third-party data: 16 tabular outlier-detection datasets from
> ADBench (Han et al., NeurIPS 2022), available at https://github.com/Minqi824/ADBench
> (`adbench/datasets/Classical/`), and 13 ODDS/ADBench datasets as distributed with the ADOD
> code (https://github.com/Qian-Lily/ADOD). No restrictions apply; all data are openly
> accessible in the same manner as used by the authors.

## Derived data (generated by this study)

| Location | Underlies | Contents |
|----------|-----------|----------|
| `revision/experiments/E1/raw/`  | E1, E4; Tables 6, 7; Fig 1; S2 Table | ρ, ρ̃ and the alternative definitions per (dataset, method, replicate) at p = 10% |
| `revision/experiments/E1b/raw/` | E1b | ρ at p ∈ {1, 5, 10}% |
| `revision/experiments/E2/raw/`  | E2; Fig 2 | ρ against n, 24 datasets, p from 0.5% to 50% |
| `revision/experiments/E2b1000/`, `E2b2000/`, `E2b5000/` | E2b; Table 8 | ρ at reference sets of 1,000, 2,000, 5,000 records |
| `revision/experiments/E3/raw/`  | E3 | ρ against k and p for LOF and KNN |
| `revision/experiments/E5/raw/`  | E5; Table 9 | ρ and runtimes on the full-size datasets |
| `revision/experiments/X5/raw/`  | E6; Table 10 | ρ against the number of trees |
| `revision/experiments/E6b/`     | E6 (oblique splits) | per-record depth variances, axis-parallel vs oblique trees |
| `revision/experiments/X6/raw/`  | E7 | ρ against the dimension d (synthetic data) |
| `revision/experiments/X7/raw/`  | E8 | ρ by anomaly type (local, global, clustered) |
| `revision/experiments/validation/` | S1 Table; Table R1 of the response letter | implementation checks |
| `revision/experiments/paper_numbers.csv`, `dataset_characteristics.csv` | numbers quoted in the text; Table 4, S3 Table | written by `paper_numbers.py` |

All are produced with fixed seeds (replicate `r` uses seed `42 + r`; in the oblique-split check of E6, the
axis-parallel tree `t` uses `42 + 10t` and the oblique tree `t` uses `42 + 10t + 1`) by the scripts in `revision/code/`, except the E5 runtimes, which are wall-clock
measurements; the README lists which script produces each table, figure and number.

## Third-party benchmark datasets (16 core datasets)

All obtained from **ADBench** — Han, Hu, Huang, Jiang & Zhao, *"ADBench: Anomaly
Detection Benchmark"*, NeurIPS 2022 — at
<https://github.com/Minqi824/ADBench> (`adbench/datasets/Classical/`).
`python download_datasets.py` downloads them and checks each file against the SHA-256 of the copy used
for the paper.
