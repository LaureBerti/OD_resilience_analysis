# Earlier version of the analysis (superseded)

This folder holds the scripts, results, tables and figures of an earlier version of the analysis.
They are kept for reference only. They are superseded and do not underlie any table or figure of
the paper; in particular, the earlier EIF and ADOD implementations used here were incorrect.

The current pipeline, results and Supporting Information are in `revision/` (see the top-level README).
The scripts here are not maintained and are not expected to run from this location.
